# CivicSense Frontend Prototype

## Run locally
1. Extract the ZIP file.
2. Open the `CivicSense-frontend` folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Included
- Responsive civic admin dashboard
- Sample complaint data
- Complaint submission modal
- Category and status filters
- Search across complaints
- Status updates
- Rule-based demo priority scoring and duplicate-location checks
- Schematic, illustrative campus map

## Notes
This is a frontend-only hackathon prototype. It does not use a backend/database or a real AI model. The map is illustrative, not a real geospatial map. Connect a secure backend and verified geospatial data before production use.
